# AI Onboarding Artefacts

These files are mock company-specific onboarding material for the "how to onboard your AI" demo.

They are intentionally small, but each one shows a different kind of context a team might check into a codebase:

- `INSTRUCTIONS.md` gives the AI default project judgment.
- `skills/design-language/SKILL.md` teaches house style for UI work.
- `skills/code-review-ways-of-working/SKILL.md` teaches how this team raises review requests.
- `agents/code-review.md` defines a focused code reviewer.
- `agents/ux-review-mini-golf-enthusiast.md` defines a domain-fluent UX reviewer.

The point is not that Putty needs process. The point is that even a tiny app can demonstrate how local preferences, constraints, and domain taste make AI output more specific to the team.
